## Introduction

This is the introduction to authentication in One Identity Manager. It explains
the high-level concepts that the rest of the manual builds upon.

### Goals

The goals section describes what authentication aims to achieve: verifying the
identity of a principal before granting access to protected resources.

## Authentication Modules

### OAuth Module

The OAuth module implements the OAuth 2.0 authorization framework. It supports
the authorization code grant and the client credentials grant.

### SAML Module

The SAML module integrates with SAML 2.0 identity providers for browser-based
single sign-on across federated domains.
